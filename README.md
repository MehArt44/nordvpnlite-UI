# nordvpnlite-UI


## 🚀 آسان (Installation)

برای نصب سریع، کافیست از طریق نرم‌افزارهای SSH (مانند PuTTY یا Terminal) به روتر خود متصل شوید و دستور زیر را اجرا کنید:
```bash

wget -O /tmp/nordvpnlite.0.1.0-r1_UI_Final.sh https://github.com/MehArt44/nordvpnlite-UI/releases/download/0.1.0-r1/nordvpnlite.0.1.0-r1_UI_Final.sh

sh /tmp/nordvpnlite.0.1.0-r1_UI_Final.sh install

```
